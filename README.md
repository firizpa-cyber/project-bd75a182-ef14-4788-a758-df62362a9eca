# Мой Склад Камер

Разработать современную, профессиональную и максимально удобную CRM-систему «Мой склад» для магазина техники и камер видеонаблюдения. Полностью русский интерфейс, открытый минималистичный дизайн, светлая и тёмная темы, плавные анимации, красивые иконки, визуальные карточки и минимум текста. Самостоятельно проанализировать специфику магазина и продумать необходимые разделы, функции и пользовательские сценарии, включив только действительно важные инструменты для управления магазином, товарами, продажами, ценами и складскими остатками. Интерфейс должен быть интуитивным, быстрым и полностью адаптивным, с особым вниманием к удобству использования со смартфона. На первом этапе реализовать исключительно Frontend со всей интерактивностью, локальными mock-данными и без Backend и базы данных. Подготовить демонстрационное наполнение реалистичными товарами для магазина камер видеонаблюдения, включая фотографии из интернета. Реализовать моковую авторизацию с 2–3 демонстрационными пользователями, на начальном этапе предоставить полноценный доступ только администратору с тестовыми логином и паролем. Все данные, авторизация, действия и изменения должны работать локально. Главный приоритет — лёгкость освоения, визуальная понятность, отсутствие перегруженности, современный дизайн и комфортная ежедневная работа.
